# Waslivo portfolio

React portfolio with English and Arabic layouts, built with Vite.

Run npm install, then npm run dev for local development. Run npm run build and node check-site.mjs to prepare and check the production output in dist.

- Six original concept studies, portfolio filters, individual project pages, service tabs, and enquiry form.
- Concept projects are demonstrations, not client commissions. Product and interior images are AI-generated.
- Navy #102A43, ivory #FAF7F0, sand #D8B47C; approved Waslivo logo.
- WhatsApp Business: +212708797386. The main contact form prepares a WhatsApp message for the visitor to review and send. The `/website-offer/` form stores submitted name, phone number, and business activity in the agency's Google Sheet for follow-up.
- Language preference is stored in the visitor's browser.
- Fonts load from Google Fonts with system fallbacks.
- Publication retains the existing private audience for owner review.
